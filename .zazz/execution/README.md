# Execution

Local mutable execution records: run logs, handoff notes, QA findings, and recovery
notes. These are active-work records, not durable documentation.

This directory is gitignored (see `.zazz/.gitignore`). Teams using Zazz Board keep
the authoritative execution records in the board; this directory is the local fallback
for repos that operate from Git plus `.zazz/execution/` only.

Contents here are not part of the committed repository.
