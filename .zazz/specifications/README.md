# Specifications

Local deliverable specifications when they are kept on disk. Per the Zazz document
model, a specification is the contract for one deliverable and may be committed here,
ignored locally, mirrored externally, or stored only in a declared tracker (for this
repo, Zazz Board).

Historically this repo stored SPECs under `.zazz/deliverables/`; those legacy files
remain there. New standalone specifications may live here under
`specifications/{slug}.md`. See [standards/spec-hygiene.md](../standards/spec-hygiene.md)
for the authoring quality bar.

This directory may be empty by default.
