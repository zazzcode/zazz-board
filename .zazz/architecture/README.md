# Architecture

Project-level or feature-level technical design documents. Architecture docs preserve
the "why" behind structural decisions before and after code is written.

Files here are durable and committed. They may retain working-doc identifiers
(`SPEC`, `INVARIANT`, `D-N`, `AC-N`) because they serve narrative spec-driven
development. See [standards/docs-hygiene.md](../standards/docs-hygiene.md) for general
markdown conventions.

This directory may be empty by default.
